# Screenshots

One picture of the site per run of the
[Make the website more interesting](../.github/workflows/make-interesting.yml) workflow, taken
right after that run's change: the home page, 1280×800, as a visitor first sees it.

Files are named for the moment they were taken, in UTC: `YYYYMMDD-HHMMZ.jpg`, so
`20261005-0428Z.jpg` is 5 October 2026 at 04:28 UTC. Sorted by name, they play back the history of
the site.
